# 🚀 Habbet Eli t7ebb
**High-Performance Media Extraction Web Tool**

### 👨‍💻 Developed by Bilel Jelassi

Habbet Eli t7ebb is a sleek, web-based application designed for seamless media extraction from various sources. Built with Python and Streamlit, it prioritizes speed, quality, and a premium user experience.

## ✨ Features
- **Dual Format Support:** Extract high-quality MP4 video or 192kbps MP3 audio.
- **Bilel's Signature UX:** Custom obsidian theme with gold accents.
- **Server-Side Processing:** No local DLLs or installation required.
- **Mobile Responsive:** Works on desktop, tablet, and smartphone browsers.

## 🛠️ Technology Stack
- **Backend:** Python 3.x
- **Extraction Engine:** `yt-dlp`
- **Frontend:** Streamlit Framework
- **Deployment:** Streamlit Cloud / GitHub
