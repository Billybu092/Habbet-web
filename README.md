# 🚀 Habbet Eli t7ebb - Universal Media Extraction Ecosystem 🇹🇳

**Habbet Eli t7ebb** is a premium, high-fidelity media extraction suite engineered to provide a seamless experience across Web and Desktop platforms. Designed to handle modern social media restrictions, this project offers a dual-engine solution for global media accessibility.

### 👨‍💻 Engineered by [Bilel Jelassi](https://github.com/Billybu092)

---

## 🌎 Two Platforms, One Mission

### 1. Web Application (Instant Access)
* **Best For:** TikTok, Facebook, Instagram, and Twitter/X.
* **Feature:** No installation required; works directly in any mobile or desktop browser.
* **UI:** Custom Obsidian-Neon theme with gold accents for a premium feel.

### 2. Windows Desktop App (The YouTube Specialist)
* **Best For:** YouTube (4K/1080p) and long-form audio extraction.
* **Why it exists:** Engineered to bypass cloud-IP blocking by using local machine processing, ensuring a 100% success rate where web servers fail.
* **Installation:** Download the official [Setup.exe here]([(https://github.com/Billybu092/Habbet-web/releases/download/v1.1.0/Habbet_Eli_t7ebb_Setup_v1.1.exe)](https://github.com/Billybu092/Habbet-web/releases/download/v1.1.0/Habbet_Eli_t7ebb_Setup_v1.1.exe)).

## ✨ Features
- **Dual Format Support:** High-quality MP4 video and crystal-clear 320kbps MP3 audio.
- **Advanced Logic:** Dynamic bitrate/resolution selectors based on format choice.
- **Hybrid Distribution:** Smart server-to-client redirection for restricted content.
- **Global Platform Support:** TikTok, FB, IG, X, YouTube, Dailymotion, and more.

## 🛠️ Technology Stack
- **Languages:** Python 3.10+
- **Extraction Engine:** `yt-dlp` (Customized options for bypassing restrictions)
- **Frontend:** Streamlit Framework (Web) / GUI Wrapper (Windows)
- **CI/CD:** GitHub Actions & Streamlit Cloud Deployment
